### GDPR Compliance
This project may contain or process personal data subject to GDPR. All users must:
- Obtain explicit consent before processing personal data
- Implement data minimization practices
- Provide data subjects with access and deletion rights
- Report data breaches within 72 hours

### CCPA Compliance (California)
If processing California residents' data:
- Provide notice of data collection
- Allow data access requests
- Honor "do not sell" requests
- Maintain comprehensive privacy policies

### Data Security
- Never commit API keys or credentials
- Use environment variables for sensitive data
- Encrypt personal identifiable information (PII)
- Implement role-based access controls
